# Ownership
the owner of the file sameone who creatid the file and the group is the users who have the access to the file.
chown:is used to chenge the file owner name.
chgrp:is used to chenge the group name.
whoami:shows the name of the user I am logged in as.
id:shows my user ID, group ID and groups.
uid: my user ID, a number the system uses for me.
gid: the group ID, the group I belong to.
groups: shows every group I am in.
In ls -l, the first name is the owner and the number or name after it is the group.
In Git Bash on Windows, chown is limited, so nothing changed when I tried it.
ls -l: shows files in long format (permissions, owner, group, size, date, name).
